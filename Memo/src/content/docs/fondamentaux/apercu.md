Cette documentation regroupe les notes Obsidian en trois blocs complementaires.

## Fondamentaux

- Structure d'un programme COBOL
- Types de donnees et clauses utiles
- Gestion des fichiers
- Entree / sortie
- Fonctions intrinseques
- Compilation

## Instructions

- Instructions simples de traitement
- Manipulation de chaines avec STRING et UNSTRING
- Boucles et paragraphes avec PERFORM

## Travaux pratiques

Les TP sont presentes comme des exercices independants avec :

- l'objectif
- les donnees d'entree
- le resultat attendu
- les contraintes principales

## Parcours recommande

1. Lire [la structure du programme](/fondamentaux/structure-programme/).
2. Revoir [les types de donnees](/fondamentaux/types-donnees/).
3. Passer par [les instructions simples](/instructions/simples/).
4. Utiliser ensuite la section TP pour pratiquer.
