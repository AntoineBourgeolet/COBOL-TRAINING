## Objectif

Charger un referentiel produit en memoire avec une table, puis enrichir un flux d'entrees.

## Entrees

### `ref_produits.csv`

```text
code;libelle;taux_commission
AUTO;Automobile;0.05
HABIT;Habitation;0.04
SANTE;Sante;0.03
```

### `ventes.csv`

```text
num;produit;montant
V001;AUTO;1000.00
V002;SANTE;200.00
V003;HABIT;500.00
```

## Resultat attendu

### `ventes_enrichies.csv`

```text
V001;AUTO;Automobile;1000.00;0.05;50.00
V002;SANTE;Sante;200.00;0.03;6.00
V003;HABIT;Habitation;500.00;0.04;20.00
```

## Contrainte

Recherche par cle en table. Si le code est inconnu, ecrire dans `ventes_rejet.csv`.
